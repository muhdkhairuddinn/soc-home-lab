# Dashboard sidebar map

The Wazuh dashboard sidebar is a list of things to learn. This table shows which day covers each one. Menu names can differ a little between Wazuh versions.

| Sidebar item | What it is for | Day |
|---|---|---|
| Endpoints Summary | List and manage agents | 3 |
| Threat Hunting | Search and read alerts | 2, 5, 20 |
| File Integrity Monitoring | Changes to watched files | 15 |
| Configuration Assessment | Hardening checks (SCA) | 16 |
| Vulnerability Detection | Known CVEs in installed software | 17 |
| MITRE ATT&CK | Alerts grouped by attacker technique | 12, 28 |
| Server management: Rules and Decoders | Read, write and test detection logic | [2](day02.md), 8, 9, 10 |
| Reporting | Export what you found | 25 |
| Discover, Visualize, Dashboards | Build your own views | 20 |

## Not in the 30 days (explore after)

- Malware Detection
- Regulatory compliance dashboards (PCI DSS, GDPR and similar)
- Cloud security modules

When you explore one, add a page for it under "My notes" and link it here. That is how this site grows into your learning journal.
