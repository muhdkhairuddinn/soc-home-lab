# Week 4: SOC work

| Day | Topic | Goal |
|---|---|---|
| Day 22 | Triage method | Handle any alert the same way every time. |
| Day 23 | Investigate a process alert | Trace a process back to what started it. |
| Day 24 | Investigate a file integrity alert | Write a second investigation from a FIM or SCA finding. |
| Day 25 | Export and report | Share findings without leaking anything private. |
| Day 26 | Secure the SIEM itself | Treat Wazuh as the most sensitive machine in the lab. |

| Day 29 | Write the case study | Turn my best investigation into a one-page story. |
| Day 30 | Polish and publish | Finish the portfolio and look back. |
