# Day 16: Security configuration assessment (SCA)

**Goal:** Read a failed hardening check and decide what to do.

## Read (15 minutes)

- [Security configuration assessment](https://documentation.wazuh.com/current/user-manual/capabilities/sec-config-assessment/index.html)

## Do

1. Open **Configuration Assessment** for `win10`.
2. Sort by Failed and pick one check. Read its rationale, remediation and the registry key or policy it checks.
3. Decide: fix it, accept the risk, or not applicable. Write the reason.

This is a real finding from your own lab, so it makes a good second investigation write-up.

## Check yourself

- Is a failed check an attack? (No. It is a setting that could be safer.)
- What would break if you applied the fix?
